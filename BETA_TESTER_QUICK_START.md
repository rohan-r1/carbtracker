# CarbTracker Beta - Quick Start Guide

Welcome to the CarbTracker closed beta! Thank you for helping test this app.

## Installation (3 minutes)

### You'll receive a TestFlight invitation email

**Steps:**
1. Check your email for "Join the CarbTracker beta on TestFlight"
2. If you don't have TestFlight, tap the link to install it from App Store
3. Tap "View in TestFlight" or "Start Testing"
4. Install CarbTracker
5. Open the app

**First launch:**
- Grant camera permissions when prompted
- Read the medical disclaimers carefully
- Tap "Get Started" on welcome screen

## How to Use

### Taking Your First Photo
1. Tap the big "Take Photo" button on home screen
2. Point camera at your meal
3. Tap the white circle to capture (or select from gallery)
4. Optionally add a description (helps AI accuracy)
5. Tap "Analyze Meal"

### Confirming Foods (Important!)
- AI will show what it detected
- Review each food item
- If wrong, select the correct option from alternatives
- Continue when all foods are confirmed

### Quick Questions
- AI may ask about portion size, preparation, etc.
- Answer if you know, or tap "Skip"
- These improve accuracy

### Final Estimate
- Review total carb count
- Use adjustment buttons if needed:
  - Quick adjust: -10, -5, 0, +5, +10, +15, +20g
  - Fine-tune: -1g, +1g buttons
- Tap "Log [X]g Carbs"

### Viewing History
- Recent meals appear on home screen
- Tap "View All" to see full history
- Pull down to refresh

## What to Test

**We need you to test 5-10 meals over the next 2 weeks**

Try different types:
- Simple meals (single items with known carbs)
- Complex meals (multiple components)
- Restaurant meals
- Beverages (especially important!)
- Home-cooked dishes
